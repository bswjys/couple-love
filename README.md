# 하트노트 (couple-love)

부부가 사랑한 날을 하트로 남기고, 우리의 리듬을 숫자로 가만히 비춰 보는 PWA.
토스처럼 담백한 흰 바탕에 부드러운 핑크 포인트를 얹었습니다.

- 주소: <https://bswjys.github.io/couple-love/>
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.
- 혼자 쓸 때는 **이 기기 브라우저(localStorage)에만** 저장되고, **부부 공유**를 켜면 두 사람 폰에 함께 저장됩니다.

## 기능

### 하트 체크
- 홈의 큰 핑크 하트를 누르면 **지금 시각으로 오늘 하트**가 기록됩니다. 여러 번 기록해도 됩니다.
- 기록을 열면 **날짜·시간·기분 태그(설렘/포근/행복/고마움)·한 줄 메모(60자)** 를 고치거나 지울 수 있어요.
- 지운 기록은 토스트의 **되돌리기**로 5초 안에 살릴 수 있습니다.
- 하루에 여러 번이면 달력 칸에 숫자 배지로 표시됩니다.

### 4종 평균 통계
| 카드 | 기간 | 보여 주는 값 |
|---|---|---|
| 월 평균 | 최근 30일 | 기록 횟수 · 평균 간격 |
| 분기 평균 | 최근 90일 | 기록 횟수 · 평균 간격 |
| 반기 평균 | 최근 180일 | 기록 횟수 · 평균 간격 |
| 연 평균 | 최근 365일 | 기록 횟수 · 평균 간격 |

- **평균 간격 = 경과 일수 ÷ 기록 횟수** (예: 최근 30일에 3회 → `평균 10일마다`).
- **통계 기준 시작일 기본값은 2026-11-01**입니다. 이 날 이전 기록은 통계(누적·평균·그래프·기분 분포)에서 빠지고, 경과 일수도 이 날부터 셉니다. 화면 위에 `통계 기준: 2026.11.01 ~`로 표시됩니다.
- 기준일보다 기간이 짧으면 **기준일부터** 계산하고(카드에 `25일치`처럼 표시), 1회뿐이면 간격 대신 `2회부터 계산돼요`로 표시합니다. 기준일을 비우면 모든 기록으로 계산합니다.
- 설정 → **통계 기준 시작일**에서 바꿀 수 있고, 옆의 **기본값**을 누르면 2026-11-01로 돌아옵니다. 부부 공유 중이면 두 폰에 함께 맞춰집니다.
- 위쪽에 **이번 달/올해 누적 횟수**, 아래에 **최근 6개월 막대그래프**와 **기분 태그 분포**가 있어요.

### 달력 하트 뷰
- 월간 달력에 기록한 날마다 하트, 2회 이상이면 숫자 배지.
- 날짜를 누르면 그날 기록 목록과 함께 **그 날짜로 기록 추가**가 됩니다.
- 미래 날짜는 기록할 수 없습니다(오늘까지).

### 오늘의 사랑 표현
- 가정사역 맥락에 맞춘 가벼운 미션 20종 중 하루 하나가 랜덤으로 나옵니다.
- **다른 미션**으로 바꾸고, **오늘 했어요**로 체크할 수 있어요.

### 부부 실시간 공유 (v2)
- 상단에서 **👩 아내 / 👨 남편** 중 누가 기록하는지 고를 수 있고, 남긴 하트에 기록자가 부드럽게 표시됩니다.
- **부부 공유 켜기** → **부부 방 코드**(2~12자, 한글 가능)를 넣으면 두 폰이 실시간으로 이어집니다. 연결되면 버튼이 **● 부부 공유 중**과 방 코드 칩으로 바뀝니다.
- **초대 링크 복사**로 보낸 `?room=` 링크를 열면 코드 입력 없이 바로 연결됩니다.
- 함께 맞춰지는 것: **하트 기록**(추가·수정·삭제) · **함께한 첫날** · **통계 기준 시작일** · **오늘의 사랑 표현**(같은 미션·완료 표시).
- 한쪽에서 하트를 남기면 다른 폰에 1~2초 안에 나타나고, 인터넷이 끊기면 이 기기에 먼저 저장한 뒤 다시 연결되면 자동으로 맞춰집니다(Firebase 실시간 스트림 + 5초 폴링).
- **PIN 잠금은 기기마다 따로**입니다. 서버에 올라가지 않고 상대 폰에도 생기지 않습니다.
- 두 기기 기록은 `updatedAt` 기준으로 합쳐지고, 지운 기록은 90일 뒤 서버에서도 정리됩니다.

### 선택형 PIN 잠금
- 기본은 꺼져 있고, 설정에서 4자리 PIN을 켜면 앱을 열 때 키패드가 먼저 뜹니다.
- 켜기: 설정 → PIN 잠금 → 새 PIN 두 번 입력 / 끄기: 현재 PIN 입력 / **PIN 번호 변경**은 현재 PIN 확인 후 새 PIN 두 번.
- 1분 이상 앱을 벗어났다 돌아오면 자동으로 다시 잠깁니다.
- PIN은 기기 안에만 저장되고 **백업 파일에는 담기지 않습니다.** 잊었다면 `PIN을 잊었어요 → 백업 파일로 복원`으로 잠금을 풀 수 있어요(복원 후 PIN을 다시 켜 주세요).

### 백업 · 복원
- 설정 → 백업: `하트노트-백업-YYYY-MM-DD.json` 파일로 내려받습니다.
- 설정 → 복원: 백업 파일을 골라 기록·시작일·통계 기준일을 되돌립니다(기존 기록은 확인 후 교체, PIN은 꺼짐).
- 설정 → 전체 삭제: 기록만 지우고 시작일은 남깁니다.

### 그 밖에
- 설정에서 **함께한 첫날**을 정하면 홈 위에 `우리 함께한 지 N일`이 표시됩니다.
- 오프라인에서도 열리도록 서비스 워커가 캐시합니다.

## 부부 공유 데이터 (Firebase Realtime Database)

- 주소: `https://baby-feeding-9f820-default-rtdb.asia-southeast1.firebasedatabase.app` (수유 앱과 같은 프로젝트, 기본값)
- 경로: `/couple_rooms/{방 코드}` — 수유 앱의 `/rooms/{방}` 과 섮이지 않습니다.

```json
{
  "couple_rooms": {
    "우리집": {
      "records": {
        "r1": { "date": "2026-11-25", "time": "21:30", "mood": "행복", "memo": "", "by": "wife", "updatedAt": 1764070200000 }
      },
      "startDate": { "value": "2014-05-10", "updatedAt": 1764070200000 },
      "mission": { "date": "2026-11-25", "idx": 5, "done": true, "updatedAt": 1764070200000 }
    }
  }
}
```

- PIN 은 이 구조에 없습니다(기기 localStorage 전용).
- Firebase 규칙이 테스트 모드(2026-12-24 만료)라면 그 전에 `rooms`·`couple_rooms` 둘 다 열어 주거나 익명 인증으로 보호해야 합니다.

  python3 .dev/test_app.py                     # 기본 기능만

- 검증 스크린샷은 `downloads/couple_love/` 에 저장됩니다.
